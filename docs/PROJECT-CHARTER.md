# Project Charter

## Project

OSRS Services Custom Web Application

## Business

- Platform name: OSRS Services
- Domain: `osrsservices.com`
- Business region: United States
- Currency: USD
- Current website: WordPress + WooCommerce
- Current hosting: Hostinger Business Web Hosting
- Delivery target: seven weeks
- Development approach: local-first, phased, Codex-led implementation

## Objectives

1. Replace the WordPress storefront with a custom web application.
2. Give the owner complete control through a custom admin panel.
3. Provide purpose-built ordering experiences for different OSRS service types.
4. Support guests, registered customers, staff roles, real-time chat, pricing engines, inventory, and order management.
5. Preserve the recognizable black/white/green OSRS Services identity while delivering an original premium interface.
6. Prepare payment methods for later activation without requiring a redesign.

## Confirmed internal roles

- Super Administrator
- Editor
- Support Agent

## Confirmed payment presentation

- PayPal
- Apple Pay
- Google Pay
- Credit/debit cards
- Payoneer
- Cryptocurrency
- OSRS GP

All provider-based methods are disabled until configured with approved live credentials.

## Confirmed pricing add-ons

- Discord Stream: default +2%, optional, editable
- Secure 100+ Combat Service: default +10%, optional, editable and applicable only where enabled
- Delivery: Standard, Priority, Express buttons
- Priority and Express fees/times remain inactive until configured by the client

## Success definition

The system is launch-ready when all agreed modules are implemented, tested, responsive, manageable through admin, and documented. Payment-provider approval is an external dependency; an integration can be technically complete while remaining disabled pending approval.
